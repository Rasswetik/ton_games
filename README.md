# Luna Gifts - Web App

Веб-приложение для крафта подарков на базе Flask.

## Установка локально

```bash
pip install -r requirements.txt
python app.py
```

Приложение будет доступно на http://localhost:5000

## Деплой на Timeweb Cloud

1. Создайте приложение Python на Timeweb
2. Используйте Git для деплоя или загрузите файлы через FTP
3. Убедитесь, что файл `app.py` запускается правильно

## Файловая структура

- `app.py` - основное Flask приложение
- `templates/` - HTML шаблоны
- `static/` - CSS, JS и изображения
- `static/data/` - JSON данные (gifts.json)
